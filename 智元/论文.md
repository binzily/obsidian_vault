# 1.RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control，2023

把两类数据混合训练：
`互联网图文任务：图像 → 文本回答`
`机器人任务：图像 + 指令 → 动作 token`
所以二者都可以使用同一个 Transformer 输出层和交叉熵损失。

这样理解 RT-2：
```markdown
第一层：理解
“哪个是苹果，用户要求做什么”

第二层：预测动作编码
[179,128,102,128,141,128,255]

第三层：动作解码
末端向前 2cm、向下 1cm、夹爪闭合

第四层：传统机器人控制
逆运动学 → 目标关节角 → 电机执行
```
RT-2 并不害怕 action token 和 language token **共用词表**，反而就是刻意利用这种**统一 token** 空间。
RT-2 的问题：
1.分桶这种方法本身就会存在误差
2.高频连续动作通常变化很**平滑**，大量**相邻 token** 几乎完全相同。模型很容易只学会“复制上一步”，而没有真正理解任务。
3.各维度独立分箱，忽略动作结构；传统的“每维度、每时刻分箱”在高频灵巧任务上效果很差。

# 2.π₀: A Vision-Language-Action Flow Model for General Robot Control，2024

π₀保留预训练 VLM 负责理解图像和语言，同时增加一个基于 **flow matching** 的动作专家，生成一整段连续动作：
```
VLM：理解任务和场景
        ↓
Action Expert：从噪声逐渐生成连续动作块
```
它在单臂、双臂和移动操作平台的混合数据上训练，并展示了叠衣服、收拾桌面、组装纸箱等复杂操作。

VLM 特征和噪声究竟在哪里融合?
输入序列可以简化为：
$$\left[\;\underbrace{C}_{\text{图像+语言}},\; \underbrace{q}_{\text{机器人状态}},\; \underbrace{E^\tau}_{\text{带噪动作}}\;\right]$$
π₀ 使用 blockwise attention mask：
```
图像/语言：只能看图像/语言
机器人状态：可以看图像/语言和自身
动作 tokens：可以看图像/语言、状态和全部动作 tokens，动作噪声主动attn图像语言机器人状态信息，然后去噪。
```

# 3.π₀.₅: a Vision-Language-Action Model with Open-World Generalization，2025

π₀基本思路是：
$\text{图像＋具体指令}\rightarrow\text{连续动作}$

π₀.₅
变成：
$\text{图像＋总体任务} \rightarrow \text{当前子任务} \rightarrow \text{连续动作}$

从技术演进看，**π₀.5 的核心是“异构数据联合训练 + 高低层统一”**：所谓异构联合训练，就是把网页图文/VQA/检测数据、不同机器人示范、语言标注的子任务等一起训练，使同一个 VLA 既能先用自回归语言生成高层子任务（如“先拿起杯子”），又能让 **action expert**用 Flow Matching 生成低层 action chunk； **KI（Knowledge Insulation，知识隔离）其实是随后提出的 π₀.5+KI 改进**，它发现 action expert 的连续动作 loss 如果直接反传进预训练 VLM，会破坏 VLM 原有的语言/视觉知识，所以在 action expert→VLM 之间 **stop-gradient**，但又不能完全冻结 VLM，于是额外让 VLM 学 **FAST 离散动作 token**（一种把连续机器人动作压缩成离散 token 的方法，本质上是离散余弦变换压缩）。π₀.6 的 RECAP（RL with Experience & Corrections via Advantage-conditioned Policies），它把“人类示范 + 机器人犯错后人工接管纠正 + 机器人自主运行得到的成功/失败轨迹”一起利用，先学一个 **value function（估计当前状态离最终成功还有多好）**，再由前后价值变化得到 **advantage（优势：某个动作让未来变好了还是变坏了）**，训练时把 advantage 也作为条件告诉 VLA，部署时要求它生成“高 advantage 动作”。（价值函数得到的做法是：机器人先执行出完整轨迹，每条 episode 最后只需要知道“成功还是失败”；然后定义奖励：中间每一步 r_t=-1，成功结束时 r_T=0，失败结束时给一个很大的负数 −Cfail。**越接近完成，value 就越大，最终成功时变成 0，失败轨迹则得到很低的 value**。）
